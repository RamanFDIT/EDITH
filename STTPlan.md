 STT Migration Plan: Hugging Face to Gemini Backend                                                                                                                                                                                                                                │
│                                                                                                                                                                                                                                                                                   │
│ Objective                                                                                                                                                                                                                                                                         │
│ Migrate the frontend's Speech-to-Text (STT) implementation from the local, client-side Hugging Face model (whisperWorker.js) to the existing backend /api/voice endpoint, which utilizes the Gemini API.                                                                          │
│                                                                                                                                                                                                                                                                                   │
│ Motivation & Impact                                                                                                                                                                                                                                                               │
│  * Performance: Offloads heavy STT compute from the user's browser, preventing potential UI jank and battery drain.                                                                                                                                                               │
│  * Accuracy: Gemini 2.5 Flash STT generally provides higher accuracy and faster inference for complex queries than the client-side whisper-tiny model.                                                                                                                            │
│  * Simplicity: Consolidates audio handling into the existing backend streaming architecture, simplifying the React Input component.                                                                                                                                               │
│                                                                                                                                                                                                                                                                                   │
│ Implementation Steps                                                                                                                                                                                                                                                              │
│                                                                                                                                                                                                                                                                                   │
│ 1. Update frontend/src/Pages/Home/Home.jsx                                                                                                                                                                                                                                        │
│  * Create a new handleAudioSubmit(audioBlob) function.                                                                                                                                                                                                                            │
│  * This function will construct a FormData payload containing the audio blob, sessionId (from activeSessionId), and projectId (from activeProjectId).                                                                                                                             │
│  * It will make a POST request to ${API_URL}/api/voice, passing the required X-User-Email header (from userEmail in AppContext) for authentication.                                                                                                                               │
│  * Upon a successful response, it will pass the response.body stream directly to the already-existing handleVoiceStream method to parse the Server-Sent Events (SSE).                                                                                                             │
│  * Update the <Input> component to pass onAudioSubmit={handleAudioSubmit} instead of onVoiceStream={handleVoiceStream}.                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                   │
│ 2. Update frontend/src/components/Input/Input.jsx                                                                                                                                                                                                                                 │
│  * Remove Worker Logic: Delete all workerRef, isModelReady state, and the useEffect that initializes whisperWorker.js.                                                                                                                                                            │
│  * Update Props: Change onVoiceStream to onAudioSubmit.                                                                                                                                                                                                                           │
│  * Simplify Recording Stop: In the mediaRecorder.onstop handler, remove the complex audio context decoding (Float32Array conversion). Simply package the chunks into a Blob and call onAudioSubmit(blob).                                                                         │
│  * Remove Load States: Remove the "Loading STT model..." placeholder logic, allowing the input to be ready immediately.                                                                                                                                                           │
│                                                                                                                                                                                                                                                                                   │
│ 3. Cleanup (Optional but Recommended)                                                                                                                                                                                                                                             │
│  * Delete frontend/src/workers/whisperWorker.js.                                                                                                                                                                                                                                  │
│  * Remove @huggingface/transformers from frontend/package.json if no other features require it.                                                                                                                                                                                   │
│                                                                                                                                                                                                                                                                                   │
│ Verification                                                                                                                                                                                                                                                                      │
│  * Test voice recording in the browser to ensure the audio blob is sent correctly.                                                                                                                                                                                                │
│  * Verify the backend receives the audio, transcribes it via Gemini, and streams the user_text and AI response back to the UI.
